# 05 - Introduction to LangSmith

课程来源：[Introduction to LangSmith - LangChain Academy](https://academy.langchain.com/courses/intro-to-langsmith)

## 学习目标

掌握 LangSmith 的核心功能：追踪、调试、评估 LLM 应用，建立可观测性意识。

## 主要内容

- Tracing：追踪 LLM 调用链路，理解每一步的输入输出
- Debugging：通过 Trace 界面定位问题，减少盲目排查
- Evaluation：构建评估数据集，用 LLM-as-judge 方法对比模型/提示词效果
- Datasets & Experiments：版本化管理测试集，持续跟踪应用质量
