# Introduction to LangChain - Python

- LCEL（LangChain Expression Language）现代语法
- 链式组合与对话记忆
- RAG 流程：文档加载、分块、向量存储、检索
- Agent 构建：工具定义、ReAct 模式
- 调试与追踪

> 框架是手段，不是目标。理解底层在做什么比记住 API 更重要。
